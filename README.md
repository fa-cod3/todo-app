# Todo App

Aplicación de tareas con React y Node.js.

## Features
- ✅ Crear, editar, eliminar tareas
- ✅ Marcar tareas completadas
- ✅ Persistencia en base de datos
- ✅ API REST completa

## Stack
- Frontend: React
- Backend: Node.js + Express
- Database: PostgreSQL

## Cómo usar
```bash
npm install
npm start
```
